## What I build

I like building for the web and turning ideas into products. I care a lot about keeping my code clean. I also write about tech, how I work, and gaming.

AI coding agents are part of how I work now. I use them to plan, write, and review code, and I own the parts they get wrong. Most of the projects above were built this way, which is how I ship in stacks I don't use every day.

Day to day I work with TypeScript on Vue and React, and Node (Hono, Express, NestJS, Fastify) with GraphQL or REST and PostgreSQL/MySQL. I ship with Docker, Kubernetes, and Cloudflare, and test with Playwright, Cypress, and Vitest.
